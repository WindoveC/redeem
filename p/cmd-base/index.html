追加 PATH 路径

Bash (Linux / macOS / WSL)

注意： Bash 中路径之间使用冒号 : 分隔。

  1. 临时生效（仅当前终端会话）

    1

    export PATH=$PATH:/your/new/path

  2. 永久生效（当前用户）

    将上面的 export 命令追加到配置文件中。

    1
2
3

    echo 'export PATH=$PATH:/your/new/path' >> ~/.bashrc
# 然后刷新配置使其立即生效
source ~/.bashrc

    (注：如果是 macOS，默认 shell 是 zsh，应将 ~/.bashrc 替换为 ~/.zshrc)

CMD (Windows 命令提示符)

注意： CMD 中路径之间使用分号 ; 分隔。

  1. 临时生效（仅当前 CMD 窗口）

    1

    set PATH=%PATH%;C:\your\new\path

  2. 永久生效

    在 CMD 中永久修改环境变量通常有两种方式：

    • 方式 A：使用 setx 命令（需谨慎）

      1

      setx PATH "%PATH%;C:\your\new\path" [/m]

      ⚠️ 严重警告： setx 命令有 1024 个字符的长度限制。如果你的当前 PATH 本来就很长，使用这个命令会截断后面的路径，导致系统环境变量损坏！建议只设置用户级变量，或者直接用方式 B。

    • 方式 B：通过图形界面设置（最安全推荐）
      在 CMD 中直接输入以下命令打开环境变量设置窗口：

      1

      sysdm.cpl

      然后点击 “高级” -> “环境变量”，手动在“用户变量”或“系统变量”中找到 Path，点击“编辑”并“新建”添加你的路径。

PowerShell (Windows)

注意： PowerShell 中路径之间同样使用分号 ; 分隔。

  1. 临时生效（仅当前 PowerShell 窗口）

    1

    $env:PATH += ";C:\your\new\path"

  2. 永久生效（推荐方法）

    PowerShell 可以直接调用 .NET 类来安全地修改注册表中的环境变量，不会有 1024 字符的截断限制。

    修改当前用户的环境变量（无需管理员权限）：

    1

    [Environment]::SetEnvironmentVariable("PATH", $env:PATH + ";C:\your\new\path", "User")

    修改系统级环境变量（需要以管理员身份运行 PowerShell）：

    1

    [Environment]::SetEnvironmentVariable("PATH", $env:PATH + ";C:\your\new\path", "Machine")
💡 通用注意事项与避坑指南：
  1. 路径中如果包含空格（例如 C:\Program Files\MyApp），在 Bash 中需要加引号：export PATH=$PATH:"/your/path with space"；在 CMD 和 PowerShell 中通常不需要特殊处理，但加上引号更稳妥。
  2. 立即生效问题：永久修改环境变量后，已经打开的终端窗口不会自动更新，你需要关闭并重新打开终端窗口，新路径才会生效。
  3. 避免重复追加：如果你频繁运行永久追加命令，PATH 里面会充满重复的路径。高级用户在写脚本时通常会先判断路径是否已存在再决定是否追加。

注释

常规单行注释 ::
代码块（括号内）注释 REM
行末注释 & REM

行头 @：禁止回显（suppress echoing）当前命令本身到命令行窗口。

3. 文件夹

  1. robocopy

更强大、可靠

环境变量

  • 临时 / 终端变量
1

  1. 本地 / 用户环境 设置
1

setx MACHINE Brand1
  1. 系统环境 设置
1

setx MACHINE Brand1 Computer /m
  1. 本地环境 复制
1

setx MYPATH %PATH%
  1. 本地环境 追加
1

setx PATH %PATH%;content
  1. 本地环境 置空
1

setx path ""
  1. 远程 要在名为 computer1 的远程计算机上将本地环境中的 MACHINE 环境变量设置为 Brand1，请键入：
1

setx /s computer1 /u maindom\hiropln /p p@ssW23 MACHINE Brand1
  1. 取注册表项
1

setx TZONE /k HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\TimeZoneInformation\StandardName
  1. 显示文件的内容以及坐标
1

setx /f ipconfig.out /x
  1. 取文件内容 坐标 5,11 处****
1

setx IPADDR /f ipconfig.out /a 5,11
  1. 取文件内容 带有分隔符 #$* 的坐标 5,3 处
1

setx OCTET1 /f ipconfig.out /a 5,3 /d #$*.
  1. 取文件内容 Gateway 坐标的坐标 0,7 处找到的值，请键入：
1

setx IPGATEWAY /f ipconfig.out /r 0,7 Gateway
