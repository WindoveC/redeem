5G 移动热点 所选网络波段不可用

中国开放只有149、153、157、161、165这5个信道

1 Intel 说明

无法在 5 GHz 频段上使用 Windows® 10 移动热点功能

如何在 Windows® 10 上启用移动热点功能。

启用 Microsoft Windows® 10 移动热点 功能的步骤。

项目 内容
您看到了什么？ Windows® 10 移动热点允许您配置热点运行所在的网络频段。在某些情况下，您可能会出现错误，或者看不到 5 GHz 频段的选项。
注意 网络频段选项不受支持，且不会与前代英特尔®无线适配器一起出现。特别是英特尔®无线 7265 家族（ 修订版本 C ）以及更早的版本。
您为什么会看到它？ 某些国家/地区存在监管限制，不允许热点自行在 5 GHz 频段上运行。只有当 Windows® 10 电脑连接至位于特定（被动）的 5GHz 通道上的无线接入点 （AP） 时，您才能在 5GHz 上使用热点。
如何解决. 这种表现是预料之中的，由于存在特定国家的监管限制。但是，对于这些国家/地区，您可以先连接至获批准的 5GHz（被动）通道，然后再启动热点，来使用 5GHz 上的热点。

2 常用WiFi信道与频段

  • 2.4g频段

    2.4 GHz 频段范围内有每隔 5 MHz 分隔的频道14个（除了第14频道与第13频道相隔了 12 MHz）。[2] 40 MHz 频段可以由两个相邻 20 MHz 频段组成。取决于哪个频带是主（控制）频带，哪个频带是从（扩展）频带，路由器可能会显示成 1+5、5+1、9+13、13+9。

  • 5g频段

    • 5.2G频段

      5.2G的可用信道：36、40、44、48、52、56、60、64； 由于国家使用雷达环境中会与52、56、60、64信道冲突，因此常规模式下建议避开这些雷达信道，以免出现无线终端接入问题。

    • 5.5G频段

      5.5GHz 属于 5GHz 频段的一部分，在不同国家和地区具体的频率划分可能会有所不同。在中国，5GHz 频段的划分包括 5.470GHz - 5.725GHz 的频率范围。

    • 5.8G频段

      5.8GHz频段，中国开放只有149、153、157、161、165这5个信道； 其中可支持一组80MHz信道捆绑（149-161）或两组40MHz捆绑（149-153和157-161）； 所以165信道支持20MHz频宽。 165信道不可见是因为当前频宽为20MHz，改频宽后可见。

powercfg

1. 方案查询与激活

  • /LIST、 /L
    列出所有电源方案
  • /SETACTIVE <SCHEME_GUID> 、/S
    激活指定方案。
  • /GETACTIVESCHEME
    显示当前活动方案。

2. 方案编辑与管理

  • /DUPLICATESCHEME <SCHEME_GUID> [DEST_GUID]
    复制电源方案。DEST_GUID 不填则由系统生成。
  • /DELETE <SCHEME_GUID>、/D
    删除电源方案。
  • /CHANGENAME <SCHEME_GUID> <NAME> [DESCRIPTION]
    修改名称。
  • /IMPORT <FILE_PATH> [SCHEME_GUID]
    导入方案。
  • /EXPORT <FILE_PATH> <SCHEME_GUID>
    导出方案。

3. 设置微调 (Timeouts)

  • /CHANGE <SETTING> <VALUE>、/X
    修改当前方案的超时值。
    • <SETTING>: 必选。可选值包括：-monitor-timeout-ac, -monitor-timeout-dc, -disk-timeout-ac, -disk-timeout-dc, -standby-timeout-ac, -standby-timeout-dc。
    • <VALUE>: 必选。单位为分钟（0 表示从不）。

4. 诊断与报告

  • /BATTERYREPORT [/OUTPUT <FILE_PATH>] [/XML]
    生成电池报告。
  • /ENERGY [/OUTPUT <FILE_PATH>] [/DURATION <SECONDS>]
    能效诊断。
    • [/DURATION <SECONDS>]: 可选。扫描时长，默认 60 秒。
  • /REQUESTS
    查看睡眠拦截。无需参数。
  • /LASTWAKE
    查看上次唤醒源。无需参数。

5. 系统控制与休眠

  • /HIBERNATE {ON|OFF}、 /H
    开关休眠。
  • /DEVICEQUERY <QUERY_FLAGS>
    查询设备。
    • <QUERY_FLAGS>: 必选。常用 wake_armed (查询可唤醒系统的设备)。

#Requires -Version 5.1

<#
.SYNOPSIS
    目录树统计工具 v3.0 — 结合版
.DESCRIPTION
    融合两版优势的目录树工具。
    性能层：一次性 I/O 采集 + 记忆化累计缓存，避免重复查询和重复计算。
    功能层：通配符排除（连带子内容）、深度超限提示、隐藏过滤、彩色输出、纯文本导出。
.PARAMETER Path
    起始路径，默认当前目录。支持 Tab 补全。
.PARAMETER MaxDepth
    最大显示深度 (1~20)，默认 2。设为 0 仅显示根目录信息，-1 表示无限制。
.PARAMETER Exclude
    要排除的文件夹名称（支持通配符），例如 "bin","obj",".git","node_modules"。
    排除的文件夹及其所有子内容均不会被采集和显示。
.PARAMETER IncludeHidden
    包含隐藏/系统文件夹及 "." 前缀文件夹。默认排除。
.PARAMETER ShowSize
    显示每个文件夹的累计大小（自动转换 B/KB/MB/GB/TB）。
.PARAMETER OutputFile
    将纯文本结果导出到指定文件（不含 ANSI 颜色码）。
.EXAMPLE
    .\Show-Tree.ps1
    当前目录，2 级深度，仅显示文件数。
.EXAMPLE
    .\Show-Tree.ps1 -MaxDepth 3 -ShowSize -Exclude "node_modules",".git","bin","obj"
    3 级深度，显示大小，排除常见构建/依赖目录。
.EXAMPLE
    .\Show-Tree.ps1 -Path "C:\Projects" -MaxDepth 4 -ShowSize -OutputFile tree.txt
    指定路径，4 级深度，导出到文件。
.EXAMPLE
    .\Show-Tree.ps1 -MaxDepth -1 -IncludeHidden -ShowSize
    无限制深度，包含隐藏目录，显示大小。
.NOTES
    v3.0 结合版 — 性能优化 + 功能完善
#>

[CmdletBinding()]
param(
    [Parameter(Position = 0)]
    [string]$Path = ".",

    [ValidateRange(-1, 20)]
    [int]$MaxDepth = 2,

    [string[]]$Exclude = @(),

    [switch]$IncludeHidden,

    [switch]$ShowSize,

    [string]$OutputFile
)

# ═══════════════════════════════════════════════════════════════════
#  架构: 1.路径验证 → 2.工具函数 → 3.数据采集+过滤+缓存
#        → 4.递归绘制 → 5.输出+摘要+导出
# ═══════════════════════════════════════════════════════════════════

# ───────────────────────────────────────────────────────────────────
#  1. 路径验证
# ───────────────────────────────────────────────────────────────────

try {
    $rootPath = (Resolve-Path -LiteralPath $Path -ErrorAction Stop).Path
    if (-not (Test-Path -LiteralPath $rootPath -PathType Container)) {
        throw "目标路径不是目录"
    }
} catch {
    Write-Host "`n  ✕ 路径无效: $Path — $($_.Exception.Message)`n" -ForegroundColor Red
    exit 1
}

# ───────────────────────────────────────────────────────────────────
#  2. 工具函数
# ───────────────────────────────────────────────────────────────────

# 纯文本导出缓冲（不含 ANSI 转义码）
$exportBuf = [System.Collections.Generic.List[string]]::new()

function Format-Size([long]$Bytes) {
    if ($Bytes -ge 1TB) { return "{0:N2} TB" -f ($Bytes / 1TB) }
    if ($Bytes -ge 1GB) { return "{0:N2} GB" -f ($Bytes / 1GB) }
    if ($Bytes -ge 1MB) { return "{0:N2} MB" -f ($Bytes / 1MB) }
    if ($Bytes -ge 1KB) { return "{0:N2} KB" -f ($Bytes / 1KB) }
    return "$Bytes B"
}

function Write-TreeLine {
    <#
    .DESCRIPTION
        同时输出到控制台（彩色）和导出缓冲（纯文本）。
        树形结构线用灰色，文件夹名用青色（可覆盖），统计信息用灰色。
    #>
    param(
        [string]$Prefix    = "",
        [string]$Connector = "",
        [string]$Name      = "",
        [string]$Suffix    = "",
        [ConsoleColor]$NameColor = "Cyan"
    )
    if ($Prefix)    { Write-Host $Prefix    -ForegroundColor DarkGray -NoNewline }
    if ($Connector) { Write-Host $Connector -ForegroundColor DarkGray -NoNewline }
    Write-Host $Name -ForegroundColor $NameColor -NoNewline
    if ($Suffix)    { Write-Host $Suffix    -ForegroundColor DarkGray }
    else            { Write-Host "" }

    $exportBuf.Add("${Prefix}${Connector}${Name}${Suffix}")
}

function Write-Info {
    param(
        [string]$Text,
        [ConsoleColor]$Color = "Gray"
    )
    Write-Host $Text -ForegroundColor $Color
    $exportBuf.Add($Text)
}

# ───────────────────────────────────────────────────────────────────
#  3. 一次性数据采集（单次 I/O，后续纯内存操作）
# ───────────────────────────────────────────────────────────────────

$sw = [System.Diagnostics.Stopwatch]::StartNew()

# 3a. 全量采集（-Force 包含隐藏项）
$allFiles = @(Get-ChildItem -LiteralPath $rootPath -File      -Recurse -Force -ErrorAction SilentlyContinue)
$allDirs  = @(Get-ChildItem -LiteralPath $rootPath -Directory -Recurse -Force -ErrorAction SilentlyContinue)

# 3b. 过滤：排除隐藏/系统（属性 + "." 前缀）
if (-not $IncludeHidden) {
    $isHidden = {
        ($_.Attributes -band [IO.FileAttributes]::Hidden) -or
        ($_.Attributes -band [IO.FileAttributes]::System) -or
        $_.Name.StartsWith('.')
    }
    $allDirs  = @($allDirs  | Where-Object { -not (& $isHidden) })
    $allFiles = @($allFiles | Where-Object { -not (& $isHidden) })
}

# 3c. 过滤：通配符排除（连带排除所有子目录和子文件）
if ($Exclude.Count -gt 0) {
    # 收集命中排除规则的目录完整路径
    $excludedRoots = [System.Collections.Generic.List[string]]::new()
    foreach ($dir in $allDirs) {
        foreach ($pattern in $Exclude) {
            if ($dir.Name -like $pattern) {
                $excludedRoots.Add($dir.FullName)
                break
            }
        }
    }

    if ($excludedRoots.Count -gt 0) {
        # 判断路径是否在排除范围内（自身或子路径）
        $isUnderExcluded = {
            param([string]$FullPath)
            foreach ($er in $excludedRoots) {
                if ($FullPath.Equals($er, [StringComparison]::OrdinalIgnoreCase) -or
                    $FullPath.StartsWith($er + [IO.Path]::DirectorySeparatorChar,
                                         [StringComparison]::OrdinalIgnoreCase)) {
                    return $true
                }
            }
            return $false
        }

        $allDirs  = @($allDirs  | Where-Object { -not (& $isUnderExcluded $_.FullName) })
        $allFiles = @($allFiles | Where-Object { -not (& $isUnderExcluded $_.FullName) })
    }
}

# 3d. 构建数据结构

# 直属文件统计（按所在目录路径分组）
$DirectStats = @{}
foreach ($f in $allFiles) {
    $d = $f.DirectoryName
    if (-not $DirectStats.ContainsKey($d)) {
        $DirectStats[$d] = @{ Count = 0; Size = [long]0 }
    }
    $DirectStats[$d].Count++
    $DirectStats[$d].Size += $f.Length
}

# 父目录 → 子目录列表 映射
$ChildrenMap = @{}
foreach ($dir in $allDirs) {
    $parent = $dir.Parent.FullName
    if (-not $ChildrenMap.ContainsKey($parent)) {
        $ChildrenMap[$parent] = [System.Collections.Generic.List[IO.DirectoryInfo]]::new()
    }
    $ChildrenMap[$parent].Add($dir)
}

# 3e. 记忆化累计统计（每个目录仅计算一次，含所有子孙的文件数和大小）
$_cumCache = @{}
function Get-CumStats([string]$DirPath) {
    if ($_cumCache.ContainsKey($DirPath)) { return $_cumCache[$DirPath] }

    $count = 0; $size = [long]0

    # 加上本目录直属文件
    if ($DirectStats.ContainsKey($DirPath)) {
        $count += $DirectStats[$DirPath].Count
        $size  += $DirectStats[$DirPath].Size
    }

    # 递归加上所有子目录
    if ($ChildrenMap.ContainsKey($DirPath)) {
        foreach ($child in $ChildrenMap[$DirPath]) {
            $r = Get-CumStats $child.FullName
            $count += $r.Count
            $size  += $r.Size
        }
    }

    $result = @{ Count = $count; Size = $size }
    $_cumCache[$DirPath] = $result
    return $result
}

# 预计算根目录统计（副作用：所有子孙目录的统计也一并缓存）
$rootStats = Get-CumStats $rootPath
$sw.Stop()

# ───────────────────────────────────────────────────────────────────
#  4. 树形递归绘制（前缀追踪法）
# ───────────────────────────────────────────────────────────────────

$script:ShownFolders = 0

function Show-Tree {
    param(
        [string]$DirPath,
        [int]$Level,
        [string]$Prefix = ""
    )

    # 深度限制
    if ($MaxDepth -ne -1 -and $Level -ge $MaxDepth) { return }
    if (-not $ChildrenMap.ContainsKey($DirPath)) { return }

    # 按名称排序子目录
    $children = @($ChildrenMap[$DirPath] | Sort-Object Name)
    $n = $children.Count
    if ($n -eq 0) { return }

    for ($i = 0; $i -lt $n; $i++) {
        $child  = $children[$i]
        $isLast = ($i -eq $n - 1)

        # 连接符：中间项 ├──，末尾项 └──
        $connector   = if ($isLast) { "└── " } else { "├── " }
        # 下一级前缀：末尾项不续竖线，非末尾项续竖线
        $childPrefix = if ($isLast) { $Prefix + "    " } else { $Prefix + "│   " }

        # 累计统计标签（已缓存，O(1)）
        $stats = Get-CumStats $child.FullName
        $suffix = "  [文件: $($stats.Count)"
        if ($ShowSize) { $suffix += " | $(Format-Size $stats.Size)" }
        $suffix += "]"

        Write-TreeLine -Prefix $Prefix -Connector $connector -Name $child.Name -Suffix $suffix
        $script:ShownFolders++

        # 递归子级 或 深度超限提示
        $canRecurse  = ($MaxDepth -eq -1) -or ($Level + 1 -lt $MaxDepth)
        $hasChildren = $ChildrenMap.ContainsKey($child.FullName) -and
                       $ChildrenMap[$child.FullName].Count -gt 0

        if ($canRecurse) {
            Show-Tree -DirPath $child.FullName -Level ($Level + 1) -Prefix $childPrefix
        }
        elseif ($hasChildren) {
            # 深度已达上限，提示被折叠的子文件夹数量
            $subCount = $ChildrenMap[$child.FullName].Count
            Write-TreeLine -Prefix $childPrefix -Connector "└── " `
                           -Name "(··· 还有 $subCount 个子文件夹)" -NameColor DarkGray
        }
    }
}

# ───────────────────────────────────────────────────────────────────
#  5. 输出
# ───────────────────────────────────────────────────────────────────

$line = "━" * 52

# ── 头部 ──
Write-Host ""
Write-Host "  $line" -ForegroundColor DarkYellow
Write-Host "   目录树统计工具  v3.0" -ForegroundColor Yellow
Write-Host "  $line" -ForegroundColor DarkYellow
Write-Host ""

$exportBuf.Add("  $line")
$exportBuf.Add("   目录树统计工具  v3.0")
$exportBuf.Add("  $line")
$exportBuf.Add("")

# 参数信息
$depthLabel = if ($MaxDepth -eq -1) { "无限制" } else { "${MaxDepth} 级" }
Write-Info "  路径: $rootPath"
Write-Info "  深度: $depthLabel"
if ($Exclude.Count -gt 0) { Write-Info "  排除: $($Exclude -join ', ')" }
if ($IncludeHidden)        { Write-Info "  模式: 包含隐藏文件夹" }

Write-Host ""
$exportBuf.Add("")

# ── 根节点 ──
$rootName = Split-Path $rootPath -Leaf
if ([string]::IsNullOrEmpty($rootName)) { $rootName = $rootPath }

$rootSuffix = "  [文件: $($rootStats.Count)"
if ($ShowSize) { $rootSuffix += " | $(Format-Size $rootStats.Size)" }
$rootSuffix += "]"
Write-TreeLine -Name $rootName -Suffix $rootSuffix -NameColor White

# ── 树 ──
Show-Tree -DirPath $rootPath -Level 0

if ($script:ShownFolders -eq 0 -and $MaxDepth -ne 0) {
    Write-Info "  (无子文件夹)" -Color DarkGray
}

# ── 摘要 ──
$elapsed = $sw.Elapsed
$timeStr = if ($elapsed.TotalSeconds -lt 1) { "< 1 秒" }
           else { "{0:N1} 秒" -f $elapsed.TotalSeconds }

Write-Host ""
Write-Host "  $line" -ForegroundColor DarkYellow

Write-Host "  文件夹: " -ForegroundColor Gray   -NoNewline
Write-Host $script:ShownFolders               -ForegroundColor Cyan   -NoNewline
Write-Host "  │  文件: " -ForegroundColor Gray   -NoNewline
Write-Host $rootStats.Count                   -ForegroundColor Cyan   -NoNewline
if ($ShowSize) {

    Write-Host (Format-Size $rootStats.Size)  -ForegroundColor Cyan   -NoNewline
}
Write-Host "  │  耗时: " -ForegroundColor Gray   -NoNewline
Write-Host $timeStr                           -ForegroundColor Cyan

Write-Host "  $line" -ForegroundColor DarkYellow
Write-Host ""

# 纯文本摘要（导出用）
$summaryPlain = "  文件夹: $($script:ShownFolders)  │  文件: $($rootStats.Count)"
if ($ShowSize) { $summaryPlain += "  │  大小: $(Format-Size $rootStats.Size)" }
$summaryPlain += "  │  耗时: $timeStr"
$exportBuf.Add("")

$exportBuf.Add($summaryPlain)

# ── 导出 ──
if ($OutputFile) {
    try {
        $exportBuf -join "`r`n" | Out-File -FilePath $OutputFile -Encoding UTF8 -ErrorAction Stop
        Write-Host "  ✓ 已导出: $OutputFile`n" -ForegroundColor Green
    } catch {
        Write-Host "  ✕ 导出失败: $($_.Exception.Message)`n" -ForegroundColor Red
    }
}

使用

前置

  • 执行策略

    PowerShell 默认禁止运行脚本。首次使用前，需在管理员权限的 PowerShell 中执行：

    1
2
3
4
5

    # 查看当前策略
Get-ExecutionPolicy

# 允许本地脚本运行（推荐）
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
    策略 说明
    Restricted 禁止所有脚本（默认）
    RemoteSigned 本地脚本可运行，网络下载的需签名（推荐）
    Unrestricted 所有脚本均可运行（不推荐）

用法 

1
2

.\Show-Tree.ps1 [-Path <string>] [-MaxDepth <int>] [-Exclude <string[]>]
                [-IncludeHidden] [-ShowSize] [-OutputFile <string>]

  1. -Path

    位置参数，第 0 位（可省略参数名）

  2. -MaxDepth

    • 默认值：2
    • 范围：-1 ~ 20

  3. -Exclude

    • 默认值：@()
    • 通配符：* ？ [abc]
    • 示例：-Exclude “cache”,".*",“tmp”
    • 子文件连带排除

  4. -IncludeHidden

  5. -ShowSize

  6. -OutputFile

    • 示例：-OutputFile “tree.txt”

场景

  • 快速了解项目结构
1

.\Show-Tree.ps1 -MaxDepth 2
  • 前端项目（排除依赖目录）
1

.\Show-Tree.ps1 -MaxDepth 3 -ShowSize -Exclude "node_modules",".next","dist",".git"
  • NET 项目（排除构建产物）
1

.\Show-Tree.ps1 -MaxDepth 3 -ShowSize -Exclude "bin","obj",".vs","packages"
  • Python 项目
1

.\Show-Tree.ps1 -MaxDepth 3 -ShowSize -Exclude "__pycache__",".venv","*.egg-info","dist",".git"
  • 全盘一级概览
1

.\Show-Tree.ps1 -Path "C:\" -MaxDepth 1 -ShowSize
  • 生成项目文档用的树形文本
1

.\Show-Tree.ps1 -MaxDepth 4 -ShowSize -Exclude "node_modules",".git","bin","obj" -OutputFile project-structure.txt
  • 查找占用空间大的目录
1

.\Show-Tree.ps1 -Path "D:\" -MaxDepth 2 -ShowSize -IncludeHidden
  • 批量导出多个项目的目录树
1
2
3

@("ProjectA", "ProjectB", "ProjectC") | ForEach-Object {
    .\Show-Tree.ps1 -Path "D:\Projects\$_" -MaxDepth 2 -ShowSize -Exclude "node_modules",".git" -OutputFile "$_-tree.txt"
}
