    无法连接可能问题

    • 权限问题

      如果仍然连接不上,则可能需要修改.vscode-server文件夹及其子目录的权限,例如权限改为700,再尝试连接

      1

      chmod -R 700 /home/${user}/.vscode-server/

    • ssh 设置问题

      1. 打开远程主机的 sshd_config 文件,一般在 /etc/ssh/sshd_config 文件,找到 AllowTcpForwarding no 这一行,将 no 改为 yes,然后保存退出.

      2. 然后重启 ssh 服务

        1

        sudo systemctl restart sshd

    • known_hosts 文件问题

      如果仍然连接不上,则可能是由于 known_hosts 文件问题导致的,如果你使用了相同的 ip 地址连接过不同主机就会出现此问题,可以尝试删除 known_hosts 文件,然后再尝试连接,本地主机下执行以下命令:

      1

      rm $env:USERPROFILE\.ssh\known_hosts

      1

      del %USERPROFILE%\.ssh\known_hosts
免密登录

  1. 生成 SSH 密钥
    生成 ssh 使用的公钥/密钥对,请从客户端上的 PowerShell 或 cmd 提示符运行以下命令,具体使用方法详细见:微软官方

    1

    ssh-keygen -t rsa

    输入命令执行完成后会生成 C:\Users\${user}\.ssh , 里面会有 id_rsa(私钥 ), id_rsa.pub(公钥)两个文件, 这两个是默认名称,在执行命令时可以添加选项选择不同文件名,如果更改文件名,后面步骤对应文件路径也要更改

  2. 添加公钥到远程服务器

    id_rsa.pub(公钥)生成后,打开复制内容,打开远程主机 /home/${user}/.ssh/authorized_keys 文件,如果文件不存在就创建,然后粘贴复制的公钥内容,然后打开1.2.2 通过更新 ssh 配置文件连接中的 C:\Users\${user}\.ssh\config 配置文件,在你要连接的Host下配置 IdentityFile ,后面填写 id_rsa (私钥)路径,并保存:

    1
2
3
4
5

    Host xxx
  HostName xxx.xxx.xxx.xxx
  Port xx
  User xxx
  IdentityFile "C:\Users\${user}\.ssh\id_rsa"

    如果手动创建 /home/${user}/.ssh/authorized_keys,需要更改其权限:

    1
2

    chmod 700 /home/${user}/.ssh
chmod 600 /home/${user}/.ssh/authorized_keys

  3. 设置允许通过密钥登录

    打开远程主机的 sshd_config 文件,一般在/etc/ssh/sshd_config文件,找到PubkeyAuthentication no这一行,将 no 改为 yes,然后保存退出.
    然后重启 ssh 服务:

    1

    sudo systemctl restart sshd

Anaconda

安装

conda init 作用
  1. 自动修改你的 shell 配置文件（.bashrc/.zshrc）
  2. 让终端每次打开自动加载 conda 环境
  3. 实现直接使用 conda activate 命令
  4. 让终端显示 (base) 环境标识
  5. 不需要手动执行 eval 激活 conda
  6. 只修改用户个人配置，不需要 root 权限

使用

安装软件包

在线 
1

conda install -c conda-forge tmux -y
参数 全称 通俗解释
conda - Conda 包管理器（你服务器自带的工具，用来装软件）
install install 核心指令：安装软件包

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
requirements.txt 依赖检查工具
对比本地已安装包，输出缺失/版本冲突，不下载不安装
零第三方依赖，纯 Python 标准库
"""

import re
import sys
import argparse
import importlib.metadata

# ============================================================
#  正则 & 工具
# ============================================================

# 匹配包名: requests>=2.0 / flask[async] / numpy~=1.24
_RE_PKG = re.compile(
    r'^([A-Za-z0-9]([A-Za-z0-9._-]*[A-Za-z0-9])?)'  # 包名
    r'(\[.*?\])?'                                     # [extras]
    r'(.*)$'                                           # 版本约束
)

def normalize(name):
    """PEP 503: My_Package -> my-package"""
    return re.sub(r'[-_.]+', '-', name).lower()

def parse_ver(v):
    """'2.28.0' -> (2, 28, 0) 用于大小比较"""
    parts = []
    for p in v.strip().split('.'):
        parts.append(int(p) if p.isdigit() else p)
    return tuple(parts)

def ver_ok(installed_ver, specifier):
    """检查已安装版本是否满足约束 (支持 == != >= <= > < ~=)"""
    if not specifier:
        return True
    for s in specifier.split(','):
        s = s.strip()
        m = re.match(r'^(~=|==|!=|>=|<=|>|<)(.+)$', s)
        if not m:
            continue
        op, rv = m.group(1), m.group(2).strip()
        try:
            iv, rv = parse_ver(installed_ver), parse_ver(rv)
        except Exception:
            return True
        if op == '==' and iv != rv:  return False
        if op == '!=' and iv == rv:  return False
        if op == '>=' and iv <  rv:  return False
        if op == '<=' and iv >  rv:  return False
        if op == '>'  and iv <= rv:  return False
        if op == '<'  and iv >= rv:  return False
        if op == '~=':
            # ~=X.Y 等价于 >=X.Y, <(X+1).0
            segs = rv.strip().split('.')
            if len(segs) >= 2:
                upper = segs[:-1]
                upper[-1] = str(int(upper[-1]) + 1)
                if iv < rv or iv >= parse_ver('.'.join(upper)):
                    return False
    return True


# ============================================================
#  核心: 解析 / 查询 / 检查
# ============================================================

def parse_requirements(path):
    """
    解析 requirements.txt
    返回: [{"name", "specifier", "lineno", "raw", "skip"}, ...]
    """
    items = []
    try:
        with open(path, 'r', encoding='utf-8') as f:
            lines = f.readlines()
    except FileNotFoundError:
        print(f"\033[31m  ✗ 文件不存在: {path}\033[0m")
        return items

    for i, raw in enumerate(lines, 1):
        raw = raw.strip()
        if not raw or raw.startswith('#'):
            continue
        # 跳过 git/http 引用、文件引用
        if raw.startswith(('git+', 'http://', 'https://', 'file:')):
            items.append({"name": None, "specifier": "", "lineno": i, "raw": raw, "skip": "Git/URL"})
            continue
        if raw.startswith(('-r', '-e', '--')):
            items.append({"name": None, "specifier": "", "lineno": i, "raw": raw, "skip": "引用指令"})
            continue
        m = _RE_PKG.match(raw)
        if m:
            items.append({
                "name": normalize(m.group(1)),
                "specifier": (m.group(4) or "").strip(),
                "lineno": i, "raw": raw, "skip": None,
            })
        else:
            items.append({
                "name": raw.lower(), "specifier": "",
                "lineno": i, "raw": raw, "skip": "无法解析",
            })
    return items


def get_installed():
    """返回 {normalized_name: version}"""
    pkgs = {}
    for dist in importlib.metadata.distributions():
        name = normalize(dist.metadata.get("Name", ""))
        ver = dist.metadata.get("Version", "?")
        if name:
            pkgs[name] = ver
    return pkgs


def check(path):
    """执行检查，返回三个列表: missing, mismatch, skipped"""
    reqs = parse_requirements(path)
    installed = get_installed()

    missing, mismatch, skipped = [], [], []
    for r in reqs:
        if r["skip"]:
            skipped.append(r)
            continue
        name = r["name"]
        if name not in installed:
            missing.append(r)
        elif not ver_ok(installed[name], r["specifier"]):
            mismatch.append({**r, "installed_ver": installed[name]})
    return missing, mismatch, skipped, reqs


# ============================================================
#  输出
# ============================================================

def report(path, verbose=False):
    missing, mismatch, skipped, reqs = check(path)
    valid = [r for r in reqs if not r["skip"]]

    print()
    print(f"\033[1;36m  📋 {path}\033[0m")
    print(f"  {'─' * 52}")

    # 汇总行
    ok_count = len(valid) - len(missing) - len(mismatch)
    summary = f"  共 {len(valid)} 个包  |  "
    summary += f"\033[32m✓ {ok_count} 满足\033[0m  |  "
    summary += f"\033[31m✗ {len(missing)} 缺失\033[0m  |  "
    summary += f"\033[33m△ {len(mismatch)} 冲突\033[0m"
    if skipped:
        summary += f"  |  ○ {len(skipped)} 跳过"
    print(summary)

    # 缺失
    if missing:
        print(f"\n  \033[31m✗ 缺失 ({len(missing)})\033[0m")
        print(f"  {'─' * 52}")
        names = []
        for r in missing:
            spec = f" {r['specifier']}" if r['specifier'] else ""
            print(f"    \033[31m●\033[0m {r['name']}{spec:<20}  第{r['lineno']}行")
            names.append(r['name'])
        print(f"\n  \033[33m  pip install {' '.join(names)}\033[0m")

    # 版本冲突
    if mismatch:
        print(f"\n  \033[33m△ 版本冲突 ({len(mismatch)})\033[0m")
        print(f"  {'─' * 52}")
        for r in mismatch:
            print(f"    \033[33m▲\033[0m {r['name']:<28} "
                  f"需要 {r['specifier']:<16} 实际 {r['installed_ver']}")

    # 已安装 (verbose)
    if verbose:
        ok = [r for r in valid if r not in missing
              and r not in mismatch
              and r["name"] in {m["name"] for m in mismatch}]
        # 重新算 ok 列表
        ok = []
        missing_names = {r["name"] for r in missing}
        mismatch_names = {r["name"] for r in mismatch}
        for r in valid:
            if r["name"] not in missing_names and r["name"] not in mismatch_names:
                ok.append(r)
        if ok:
            inst = get_installed()
            print(f"\n  \033[32m✓ 已满足 ({len(ok)})\033[0m")
            print(f"  {'─' * 52}")
            for r in ok:
                ver = inst.get(r["name"], "?")
                spec = f" {r['specifier']}" if r['specifier'] else ""
                print(f"    \033[32m●\033[0m {r['name']:<28} {ver:<12}{spec}")

    # 跳过 (verbose)
    if verbose and skipped:
        print(f"\n  \033[90m○ 跳过 ({len(skipped)})\033[0m")
        print(f"  {'─' * 52}")
        for r in skipped:
            print(f"    ○ {r['raw']:<40} ({r['skip']})")

    # 结论
    if not missing and not mismatch:
        print(f"\n  \033[1;32m  🎉 所有依赖均已满足\033[0m")
    print()

    return len(missing) + len(mismatch)


# ============================================================
#  主函数
# ============================================================

def main():
    parser = argparse.ArgumentParser(
        description="对照 requirements.txt 检查依赖 (纯本地，不下载)",
        formatter_class=argparse.RawDescriptionHelpFormatter,
        epilog="""
示例:
  %(prog)s                        # 默认检查 requirements.txt
  %(prog)s requirements-dev.txt   # 指定文件
  %(prog)s -f r1.txt -f r2.txt    # 检查多个文件
  %(prog)s -v                     # 显示已安装包详情
        """,
    )
    parser.add_argument("files", nargs="*", default=["requirements.txt"])
    parser.add_argument("-f", "--file", action="append", dest="files")
    parser.add_argument("-v", "--verbose", action="store_true",
                        help="显示已安装包和跳过条目")
    args = parser.parse_args()

    files = list(dict.fromkeys(args.files))
    errors = 0
    for f in files:
        errors += report(f, verbose=args.verbose)

    sys.exit(1 if errors else 0)


if __name__ == "__main__":
    main()
